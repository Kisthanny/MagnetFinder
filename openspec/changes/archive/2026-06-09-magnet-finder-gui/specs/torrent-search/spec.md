## 新增需求

### 需求:按影视名称搜索

系统必须允许用户在 GUI 中输入影视名称并发起搜索。搜索必须经由源适配器执行，搜索过程中必须向用户呈现加载状态，搜索失败时必须显示可读的错误提示而非静默失败。

#### 场景:输入名称并搜索

- **当** 用户在搜索框输入影视名称并触发搜索
- **那么** 系统必须调用所选源的适配器进行查询，并在界面上展示返回的结果列表

#### 场景:无结果提示

- **当** 搜索完成但没有任何匹配结果
- **那么** 系统必须显示明确的"未找到相关结果"提示，而非显示空白界面

#### 场景:搜索出错提示

- **当** 搜索请求因网络或源接口异常而失败
- **那么** 系统必须显示可读的错误信息，并允许用户重试

### 需求:按清晰度筛选

系统必须支持按清晰度（2160p / 1080p / 720p）筛选结果。清晰度必须从资源名称中识别（沿用参考脚本的匹配规则），用户可选择一个最高清晰度或具体清晰度进行过滤。

#### 场景:选择清晰度过滤

- **当** 用户选择某一清晰度（如 1080p）作为筛选条件
- **那么** 结果列表必须只展示名称中匹配该清晰度的资源

#### 场景:未识别清晰度的资源

- **当** 某资源名称中无法识别出任何已知清晰度
- **那么** 系统必须将其归为"未知清晰度"，且在用户启用清晰度筛选时根据筛选条件决定是否展示

### 需求:按季与集筛选

系统必须支持按季（Season）与集（Episode）筛选结果，匹配规则必须复用参考脚本的正则（`S0X|Season X`、`E0X|Episode X`）。集筛选必须依赖季的存在，禁止在未指定季的情况下进行集筛选。

#### 场景:按季筛选

- **当** 用户输入季数进行筛选
- **那么** 结果列表必须只展示名称匹配该季的资源

#### 场景:按集筛选需要季

- **当** 用户尝试在未指定季的情况下输入集数筛选
- **那么** 系统必须阻止该操作并提示用户先指定季数

#### 场景:按指定集筛选

- **当** 用户在已指定季的前提下输入一个或多个集数
- **那么** 结果列表必须只展示名称同时匹配该季与所选集的资源

### 需求:结果排序与展示

系统必须以列表形式展示搜索结果，每条至少包含名称、做种数（seeders）、体积、清晰度标签。结果默认必须按做种数降序排序。

#### 场景:默认按做种数排序

- **当** 搜索结果展示在列表中
- **那么** 列表必须默认按做种数从高到低排序

#### 场景:展示关键字段

- **当** 某条结果被渲染到列表
- **那么** 该条必须展示名称、做种数、体积与清晰度标签等关键信息
