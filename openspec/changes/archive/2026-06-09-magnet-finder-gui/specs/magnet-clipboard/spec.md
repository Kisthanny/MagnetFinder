## 新增需求

### 需求:生成标准磁力链接

系统必须能够由归一化结果生成标准磁力链接，格式为 `magnet:?xt=urn:btih:<infoHash>&dn=<编码名称>&tr=<编码tracker>...`。生成时必须对显示名称与每个 tracker 进行 URL 编码，并附加预置的 tracker 列表（复用参考脚本中的 tracker）。

#### 场景:由结果生成磁力链接

- **当** 某条结果具备有效 `infoHash`
- **那么** 系统必须生成包含该 hash、URL 编码后的名称以及全部预置 tracker 的标准磁力链接

#### 场景:缺失 infoHash 无法生成

- **当** 某条结果在回退获取后仍无有效 `infoHash`
- **那么** 系统必须禁止生成磁力链接，并向用户提示该资源不可用或引导其访问详情页

### 需求:复制磁力链接到剪贴板

系统必须支持用户选中某条结果后将生成的磁力链接复制到系统剪贴板，并在复制成功后给出明确反馈。

#### 场景:复制成功反馈

- **当** 用户对一条具备有效磁力链接的结果触发复制
- **那么** 系统必须将磁力链接写入系统剪贴板，并显示"已复制到剪贴板"的提示

#### 场景:复制不可用资源

- **当** 用户尝试复制一条无法生成磁力链接的结果
- **那么** 系统禁止写入无效内容到剪贴板，并必须提示该资源不可复制
