## 为什么

应用当前只有一套暗色外观，无法切换。部分用户偏好亮色或希望跟随系统外观（日间亮、夜间暗）。需要提供主题切换，提升不同环境与偏好下的可用性与观感一致性。

## 变更内容

- 在设置面板中新增「主题」选项（与现有的语言切换并列），提供三个选项：**亮色 / 暗色 / 跟随系统**。
- 引入亮色配色方案：将现有仅暗色的 CSS 变量重构为「亮色 / 暗色」两套，按主题切换。
- 「跟随系统」通过 Electron `nativeTheme` 解析系统外观并实时响应系统切换（跨平台，不局限于 macOS）。
- 主题偏好由主进程作为权威源并持久化（与语言一致，写入 `settings.json`），切换即时生效，重启后保留。
- 默认值为「跟随系统」。

## 功能 (Capabilities)

### 新增功能
- `theme-switching`: 在设置中切换亮色/暗色/跟随系统主题，偏好持久化、即时生效，「跟随系统」实时响应 OS 外观变化。

## 影响

- 渲染层：新增 `ThemeProvider` 与 `useTheme`，在根节点应用 `data-theme`；`SettingsPanel` 增加主题下拉；`styles.css` 重构为亮/暗两套变量。
- 主进程：`settings.ts` 增加 `theme` 字段；新增主题状态模块与 `nativeTheme` 接入；新增 `theme:get/set` IPC 与 `theme:changed` 广播。
- 预加载：`window.api` 增加 `getTheme/setTheme/onThemeChanged`，并更新类型声明。
- 多语言资源：5 个 locale 增加主题相关文案（标签与三个选项），`messages.ts` 类型同步。
- 不改变搜索/磁力/轮询等核心功能逻辑。
